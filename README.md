Base Onchain Identity

Base Onchain Identity هو مشروع مفتوح المصدر لبناء هوية رقمية لامركزية (On-chain Identity) تعتمد على محافظ Web3 والتوقيع المشفر ومعايير الهوية اللامركزية (DID).

الرؤية

يهدف المشروع إلى توفير طبقة هوية رقمية يمكن التحقق منها تشفيريًا، لتكون أساسًا لتطبيقات Web3 والهوية الذاتية السيادة (Self-Sovereign Identity).

المميزات الحالية

- ربط المحافظ مثل MetaMask.
- توقيع الرسائل (Message Signing).
- التحقق من صحة التوقيع.
- إثبات ملكية عنوان المحفظة.
- إنشاء معرفات DID.
- دعم مستندات DID.
- واجهة مبنية باستخدام React وTypeScript.

خارطة الطريق

- دعم Verifiable Credentials (VC).
- دعم ملفات ".well-known/did.json".
- إضافة نظام السمعة (Reputation).
- إضافة Identity Score.
- دعم Base وEthereum والشبكات المتوافقة مع EVM.
- إضافة Web3 Login باستخدام SIWE.
- دعم QR Verification.
- دعم On-chain Passport.

التقنيات المستخدمة

- React
- TypeScript
- Vite
- ethers.js
- MetaMask
- Base Network
- Ethereum
- DID

التشغيل محليًا

npm install
npm run dev
