# Base Onchain Identity

مشروع تجريبي لبناء **هوية رقمية قائمة على البلوكشين (On-chain Identity)**  
باستخدام React + TypeScript + Vite.

## الفكرة
إنشاء واجهة ويب بسيطة تمثل هوية رقمية يمكن ربطها لاحقًا بـ:
- DID (Decentralized Identifier)
- محافظ Web3
- ملفات `.well-known/did.json`

## التقنيات المستخدمة
- React
- TypeScript
- Vite

## التشغيل محليًا
```bash
npm install
npm run dev

# Base Onchain Identity

مشروع تجريبي لبناء **هوية رقمية قائمة على البلوكشين (On-chain Identity)**  
يعتمد على التوقيع بالمحفظة وربط الهوية بمعرّف لا مركزي (DID) قابل للتحقق.

## ✨ الفكرة
إنشاء هوية ويب بسيطة لكنها **قابلة للتحقق تشفيريًا**، تمهيدًا لاستخدامها في:
- إثبات ملكية العنوان (Wallet Ownership)
- أنظمة DID / SSI
- Web3 Login
- Verifiable Credentials لاحقًا

## 🧩 ما الذي يقدمه المشروع؟
- ربط المحفظة (MetaMask)
- توقيع رسالة (Message Signing)
- التحقق من التوقيع محليًا
- تعريف DID عبر:
Improve project documentation
Add credential and verifiable identity modules
Clean DID document
